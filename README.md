# Dependencies
Any C++ compiler

# Compilation 
The Each folder has to be compiled separatly.
```bash
g++ ./*.c
```
should work just fine.

# Running
```bash
Compiler source [dest]
``` to compile from assemble and then
```bash
VM binary
```
to run (where 'Compiler' and 'VM' are the executables).


There is still nodoccumentation on the assembly language, feel free to use my example code as a guide.
